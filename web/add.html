Plug in and install

Connect the board to this Mac with a USB-C data cable, then press Install. Chrome or Edge on a computer only. After flashing, the same window asks for your Wi-Fi.

This browser can't talk to USB devices. Open this page in Chrome or Edge on your Mac.
Needs HTTPS (or localhost).
4

Pair

Once Wi-Fi is connected, close the install window and press Pair. The board stays plugged in. This sends a one-time code over USB and the device gets its own token.
